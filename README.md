# juan-david-ospina-web

Sitio de Juan David Ospina — clases personalizadas de español, inglés y francés.

Sitio estático: HTML con CSS y JS en línea, sin build ni dependencias (solo Google Fonts).

| Archivo | Qué es |
|---|---|
| `index.html` | Página principal: paquetes, agenda del diagnóstico, precios, FAQ. Los botones abren WhatsApp. |
| `prueba.html` | Prueba de nivel de inglés (`noindex`). |
| `juan.jpg` | Foto (también se usa como imagen para compartir). |

## Correrlo en local

Abrir `index.html` en el navegador, o servir la carpeta:

```bash
npx serve .
```
